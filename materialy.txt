Polecenia SQL:
1. logowanie -> mysql -u root -p (hasło jeśli jest)
2. Pokazanie baz danych -> show databases;
3. Tworzenie baz -> create database (nazwa);
4. Wybranie bazy -> use (nazwa bazy);
5. Tworzenie tabeli -> create table (nazwa tabeli np. adresy);
6. Pokazywanie zawartości tabeli -> describe (nazwa tabeli np. adresy);
7. Usuwanie tabeli -> drop table (nazwa tabeli np. adresy);

Zapytania do bazy SQL:
SELECT -> Wybierz
* -> Wszystko z tabeli
FROM -> Z
WHERE -> Gdzie SELECT * FROM 4bgr1.auto WHERE paliwo="D";
OR i AND -> Spójniki SELECT * FROM 4bgr1.auto WHERE paliwo="D" AND typ="kombi" AND kolor="zielony" AND rocznik < 2004;
ORDER BY -> Porządek SELECT * FROM `auto` order by cena desc limit 3;
ASC -> Rosnąco
DESC -> Malejąco
BETWEEN -> Pomiędzy
LIKE -> Podobny
LIMIT -> Pokazanie ilości rekordów w tabeli SELECT * FROM 4bgr1.auto limit 200;

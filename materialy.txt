Podstawowe polecenia SQL;

1. logowanie -> mysql -u root -p (hasło jeśli jest) mysql -u root --password=hasło
2. Pokazanie baz danych -> show databases;
3. Tworzenie baz -> create database (nazwa);
4. Wybranie bazy -> use (nazwa bazy);
5. Tworzenie tabeli -> create table (nazwa tabeli np. adresy);
6. Pokazywanie zawartości tabeli -> describe (nazwa tabeli np. adresy);
7. Usuwanie tabeli -> drop table (nazwa tabeli np. adresy);
8. Wyłączenie serwera mysql -> mysqladmin -u root shutdown
9. Pokazanie tabel w bazie -> show tables;

Zaawansowane polecenia SQL;

10. Uruchomienie mysql jako samodzielnej aplikacji -> mysqld --console
11. Zatrzymanie usługi -> net stop nazwa_usługi
12. Kończenie połączenia z serwerem -> quit
13. Usuwanie bazy -> Drop database nazwa_bazy;
14. Logowanie do serwera z wyborem bazy -> mysql -u root -phasło nazwa_bazy
15. Stworzenie użytkownika bazy danych -> CREATE USER sebastian identified by 'kalafior';
16. Usuwanie użytkownika, użytkowników -> DROP USER sebastian, stachu;
17. Zmiana nazwy użytkownika -> RENAME nazwa TO nowa_nazwa;
18. Zmiana hasła do konta -> SET PASSWORD FOR nazwa = PASSWORD('nowe_hasło');

Zapytania do bazy SQL;
SELECT -> Wybierz
* -> Wszystko z tabeli
FROM -> Z
WHERE -> Gdzie SELECT * FROM 4bgr1.auto WHERE paliwo="D";
OR i AND -> Spójniki SELECT * FROM 4bgr1.auto WHERE paliwo="D" AND typ="kombi" AND kolor="zielony" AND rocznik < 2004;
ORDER BY -> Porządek SELECT * FROM `auto` order by cena desc limit 3;
ASC -> Rosnąco
DESC -> Malejąco
BETWEEN -> Pomiędzy (klauzula) można używać też na string SELECT * FROM `auto` where cena BETWEEN 5000 and 10000;
NOT BETWEEN -> Nie pomiędzy SELECT * FROM `auto` where cena not BETWEEN 10000 and 35000;
LIKE -> Podobny
LIMIT -> Pokazanie ilości rekordów w tabeli SELECT * FROM 4bgr1.auto limit 200;
INSERT INTO -> Wstawianie do tabeli INSERT INTO auto (kolor, typ) VALUES ("czerwony","test");
UPDATE -> aktualizacja danych w tabeli update auto set kolor="niebieski" where auto_id=4; oraz przykład z podnoszeniem ceny UPDATE auto set cena = cena * 1.5;
DELETE FROM -> Kasuje rekord DELETE FROM auto where auto_id = 1;
